# 🐍 Snake Water Gun Game

A beginner-friendly **Snake Water Gun Game built using Python**. Play against the computer and see who wins!

## 📌 About the Project

This project is a simple command-line game inspired by Rock Paper Scissors. It helps beginners understand Python programming concepts through an interactive game.

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

## 🎮 How to Play

Enter your choice when prompted:

- `s` — Snake 🐍
- `w` — Water 💧
- `g` — Gun 🔫

### Rules

- Snake beats Water.
- Water beats Gun.
- Gun beats Snake.
- If both players choose the same option, it's a draw.
## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Run the game:
   ```bash
    main.py
   ```

4. Enter your choice:
   - `s` for Snake
   - `w` for Water
   - `g` for Gun
